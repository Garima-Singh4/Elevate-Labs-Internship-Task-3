# Elevate-Labs-Internship-Task-3

Objective
The objective of this project was to use SQL queries to extract, analyze, and generate business insights from an Ecommerce database.

Dataset Used
Ecommerce Sales Dataset
Products, Categories, Sub-Categories, Sales, and Returns Data
Tools Used
MySQL
SQL
CSV Datasets
Work Performed
Imported and structured the Ecommerce dataset into a relational database
Performed data analysis using SQL queries
Used SELECT, WHERE, ORDER BY, and GROUP BY clauses for data exploration
Applied aggregate functions such as SUM(), AVG(), COUNT(), and MAX()
Implemented INNER JOIN and LEFT JOIN operations to combine data from multiple tables
Created subqueries to answer advanced business questions
Built SQL Views for reusable analysis
Analyzed sales performance, product categories, returns, and customer purchasing trends
Key Analysis Performed
Sales and profit analysis by category and sub-category
Top-selling and low-performing products
Return order analysis
Revenue contribution by product category
Aggregated sales metrics and business KPIs
Customer and transaction-level insights
Files Included
SQL Script File (.sql)
Ecommerce Dataset Files (.csv)
Query Output Screenshots
Project Documentation
Outcome
Developed SQL-based analytical solutions to extract actionable business insights, improve data understanding, and strengthen database querying skills using real-world Ecommerce data.
